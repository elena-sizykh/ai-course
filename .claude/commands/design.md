## Принципы дизайна

1. **Тёмный фон всегда** — светлые варианты не используются
2. **Glassmorphism** — полупрозрачные карточки с backdrop-blur
3. **Glow / neon** — свечение через box-shadow и градиентные обводки
4. **Минимум рамок** — тонкие 1px рамки с очень низкой непрозрачностью
5. **Два акцента** — фиолетовый (встреча 1, основное) + циановый (встреча 2, 1:1)
6. **Анимации** — subtle: fadeDown для бейджа, fadeUp для контента, gradShift для текста
7. **Responsive** — мобильная версия от 640px, промежуточная от 860px

## Адаптация для разных форматов

### Email / рассылка
- Тёмный фон `#07080f` (проверить поддержку в клиенте, fallback `#0a0a14`)
- Градиентный текст заменить на `color: #c084fc` (не все клиенты поддерживают clip)
- Кнопки: table-based layout, background-color вместо gradient где нет поддержки
- Разделители секций: `border-bottom: 1px solid rgba(255,255,255,.06)`
- Избегать backdrop-filter (не поддерживается в email)

### Telegram-пост
- Эмодзи вместо декоративных элементов: ✦ для лого, ▸ для списков, → для ссылок
- Жирный = **основной акцент**, курсив = _вторичная информация_
- Структура: короткий хук → основное → CTA
- Ссылки и кнопки — через inline-URL или обычный URL в конце

### Notion / Google Docs
- Заголовки: H1 фиолетовый (вручную), H2 циановый
- Callout-блоки вместо карточек
- Таблицы для сравнения (да/нет секция)
- Emoji как визуальные маркеры: 🟣 фиолетовое, 🔵 циановое, ✅ зелёное, ❌ красное
- Разделители `---` между секциями

### Презентация (Figma/Canva/Google Slides)
- Слайд: `#07080f` или `#0c0e1a` фон
- Accent colors: фиолетовый `#c084fc` и циановый `#22d3ee` для выделений
- Заголовки: белый `#f1f3ff`, подзаголовки: `#7c82a8`
- Карточки: прямоугольники с заливкой `rgba(255,255,255,.04)` и обводкой `rgba(255,255,255,.1)`
- Отступы: щедрые (80px+ вертикальные padding для секций)

### PDF / печать
- Инвертировать: светлый фон `#ffffff` или `#f8f8ff`, текст тёмный `#0f1020`
- Акценты сохранить: фиолетовый `#a855f7`, циановый `#22d3ee`
- Убрать glow-эффекты, заменить на обычные рамки с цветом
- Сохранить типографику и структуру секций

## Инструкция по применению

Когда создаёшь материал для этого проекта:
1. Выбери формат (HTML, email, пост, презентация, PDF)
2. Применяй цвета и типографику из этой системы
3. Соблюдай порядок блоков и тон коммуникации
4. Адаптируй компоненты под ограничения формата (см. раздел выше)
5. Градиентный текст — только там, где технически поддерживается

При запросе пользователя на создание материала без уточнения формата — спроси формат и цель, затем применяй соответствующие правила адаптации.
